# SmartTube VOT 32.68 R2 (2026-10-30)

Неофициальная сборка SmartTube с русским закадровым переводом видео через Яндекс. Основана на **SmartTube Stable 32.68**, вместо предыдущей **32.38 r2**.

## Изменения относительно 32.38 r2

- Обновлена кодовая база SmartTube 32.38 → 32.68.
- Перевод Яндекса приостанавливается при буферизации основного видео; при возобновлении выполняется синхронизация аудио.
- При повторной загрузке **того же** видео в пределах работающего плеера сохраняется активный/подготавливаемый перевод и избегается лишний повторный запрос. Полное пересоздание проигрывателя не поддерживается этим изменением.
- Восстановление комментариев: две ограниченные повторные попытки с задержками 1 и 3 с, отдельное сообщение об ошибке, ручная кнопка «Повторить».
- Сохранены перевод без OAuth, собственный Yandex OAuth для другого варианта голоса, раздельная громкость дорожек и состояния перевода.
