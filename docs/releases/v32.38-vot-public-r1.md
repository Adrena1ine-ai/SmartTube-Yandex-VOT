# SmartTube VOT 32.38 r1 — Yandex Voice-Over Translation

Первый публичный релиз отдельной сборки SmartTube с интегрированным Yandex
Voice-Over Translation для Android TV.

## Основное

- база: SmartTube 32.38 Stable;
- package: `org.smarttube.vot`;
- отдельная установка рядом с `org.smarttube.stable`;
- перевод EN → RU прямо из плеера;
- обычный перевод без OAuth;
- опциональный собственный Yandex OAuth-токен для lively voice;
- четыре состояния кнопки: выключено, подготовка, воспроизведение и ошибка;
- синхронизация с паузой, перемоткой и скоростью воспроизведения;
- официальный updater SmartTube отключён только для public VOT package.

## Известные особенности

На длинных или редко переводимых видео Яндекс иногда долго готовит озвучку или
возвращает ошибку. Показываются реальные состояния и доступный серверный ETA;
искусственный процент готовности не создаётся.
